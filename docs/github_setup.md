# Connect this repository to GitHub

1. Open this project folder in VS Code.
2. Open Source Control, then select **Publish Branch** or use the Command Palette command **Git: Publish to GitHub**.
3. Sign in to your GitHub account if prompted.
4. Use repository name `prism-drug-response`. Choose public if you want recruiters to view it; private if you want to develop it privately first.
5. Verify the published repository contains the README and notebook, but no raw CSVs or `.venv` directory.

The local repository already has a `main` branch and initial commit. Publishing creates the GitHub repository and connects its remote. No remote repository was created during the local setup.

For later changes, review the diff, stage relevant files, commit with a descriptive message, and use Sync Changes. Avoid committing API keys, credentials, or private datasets.
